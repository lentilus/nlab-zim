Definition

In dependent type theory, given a type AA, a type TT is a AA-null type if the function

λx:T.λy:A.x:T→(A→T)\lambda x:T.\lambda y:A.x:T \to (A \to T)

is an equivalence of types.

More generally, given a type AA and a type family B(a)B(a) indexed by a:Aa:A, a type TT is a BB-null type if the function

λx:T.λy:B(a).x:T→(B(a)→T)\lambda x:T.\lambda y:B(a).x:T \to (B(a) \to T)

is an equivalence of types for all a:Aa:A.

 Examples

  • Every type is AA-null if the type AA is a contractible type.

  • Every contractible type is ∅ \emptyset -null.

  • Every mere proposition is boolean-null.

  • Every h-set is S 1 S^1 -null.
