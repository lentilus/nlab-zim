Idea

In dependent type theory, an indexed heterogeneous identity type or indexed dependent identity type is a version of the identity type where given a type AA, a type family x:A⊢B(x)x:A \vdash B(x), terms a:Aa:A, b:Ab:A, and an identification p:a= Abp:a =_A b, the indexed heterogeneous identity type between two elements y:B(a)y:B(a) and z:B(b)z:B(b) is a type whose elements witness that yy and zz are “equal” over or modulo the identification pp.

Note on terminology

There are many different names used for this particular dependent type, as well as many different names used for the terms of this dependent type. These include the following:

name of typename of terms
indexed heterogeneous identity typeindexed heterogeneous identities
indexed heterogeneous path typeindexed heterogeneous paths
indexed heterogeneous identification typeindexed heterogeneous identifications
indexed heterogeneous equality typeindexed heterogeneous equalities

These four names have different reasons behind the use of the name:

  • The name “indexed heterogeneous identity type” comes from the fact that the indexed dependent identity type is the canonical one-to-one correspondence x:B(a),y:B(b)⊢Id B p(x,y)x:B(a), y:B(b) \vdash \mathrm{Id}_B^p(x, y) of the transport equivalence tr B p:B(a)≃B(b)\mathrm{tr}_B^p:B(a) \simeq B(b) on a type family x:A⊢B(x)x:A \vdash B(x) and an identification p:a= Abp:a =_A b, which is the dependent/heterogeneous version of the identity type for the identity equivalence id A:A≃A\mathrm{id}_A:A \simeq A

  • The name “indexed heterogeneous path type” comes from the fact that, in a context where terms of ordinary identity types can be represented as functions from an interval type, the terms of the indexed heterogeneous identity type can similarly be represented as dependent functions from the interval type. For instance, this is true in some categorical semantics and in cubical type theory.

Definitions

Using identity types

There are many different ways to define indexed heterogeneous identity types. The simplest definition states that given a type family x:A⊢B(x)x:A \vdash B(x), indexed heterogeneous identity types are an inductive family of types

a:A,b:A,p:Id A(a,b),y:B(a),z:B(b)⊢hId A,B(a,b,p,y,z)a:A, b:A, p:\mathrm{Id}_A(a, b), y:B(a), z:B(b) \vdash \mathrm{hId}_{A, B}(a, b, p, y, z)

generated by the family of elements called “heterogeneous reflexivity”

a:A,y:B(a)⊢hrefl A,B(a,y):hId A,B(a,a,refl A(a),y,y)a:A, y:B(a) \vdash \mathrm{hrefl}_{A, B}(a, y):\mathrm{hId}_{A, B}(a, a, \mathrm{refl}_A(a), y, y)

  1. for any elements a:Aa:A and b:Ab:A, any identification p:Id A(a,b)p:\mathrm{Id}_A(a,b), any elements y:B(a)y:B(a) and z:B(b)z:B(b), and any heterogeneous identification q:hId A,B(a,b,p,y,z)q:\mathrm{hId}_{A, B}(a, b, p, y, z) we have a type C(a,b,p,y,z,q)C(a, b, p, y, z, q), and

Then, we have the computation rule or beta-reduction rule. This says that for all elements a:Aa:A and y:B(a)y:B(a), substituting the dependent function t:∏ a:A∏ y:B(a)C(a,a,refl A(x),y,y,hrefl A,B(a,y))t:\prod_{a:A} \prod_{y:B(a)} C(a,a,\mathrm{refl}_A(x),y,y,\mathrm{hrefl}_{A, B}(a, y)) into the eliminator along heterogeneous reflexivity for aa and yy yields an element equal to t(a,y)t(a, y) itself. Normally “equal” here means judgmental equality (a.k.a. definitional equality), but it is also possible for it to mean propositional equality (a.k.a. typal equality), so there are two possible computation rules.

Finally, one might consider a uniqueness rule or eta-conversion rule. But similar to the case for identity types, a judgmental uniqueness rule for indexed heterogeneous identity types implies that the type theory is an extensional type theory, in which case there is not much need for indexed heterogeneous identity types, so such a rule is almost never written down. And as for identity types and other inductive types, the propositional/typal uniqueness rule is provable from the other four inference rules, so we don’t write it out explicitly.

Using function types from the interval type

There is another notion of indexed heterogeneous identity type, which uses functions from the interval type f:𝕀→Af:\mathbb{I} \to A, rather than elements a:Aa:A, b:Ab:A, and p:a= Abp:a =_A b:

Finally, one might consider a uniqueness rule or eta-conversion rule. Indexed heterogeneous identity types of arbitrary arity

The usual notion of indexed heterogeneous identity types, binary indexed heterogeneous identity types, represents the notion of when two elements of a type family (B(x)) x:A(B(x))_{x:A} are equal or identified with each other. One can generalize this to the notion of when a family of elements of a type family (B(x)) x:A(B(x))_{x:A} are equal or identified, that is, indexed heterogeneous identity types of arbitrary arity.

Given a type AA and an index type II, a family of elements in AA of arity II is represented by a function x¯:I→A\overline{x}:I \to A, and given such an x¯:I→A\overline{x}:I \to A, a family of elements in (B(x)) x:A(B(x))_{x:A} of arity II is represented by a dependent function y¯:∏ i:IB(x¯(i))\overline{y}:\prod_{i:I} B(\overline{x}(i)).

The elements of indexed heterogeneous identity types of arity II are called heterogeneous identifications of arity II.

Closely related to indexed heterogeneous identity types of arbitrary arity are the indexed heterogeneous bridge types, which can also come with arbitrary arity. Indexed heterogeneous identity types and indexed heterogeneous bridge types share some commonalities with each other:

  • they are reflexive type families that come with a notion of dependent function application to identifications (or bridges for indexed heterogeneous bridge types);

  • they are used in the induction principle of higher inductive types;

  • they are used to satisfy various notions of extensionality such as dependent function extensionality;

There are many different ways to define indexed heterogeneous identity types of arity II. The simplest definition states that given a type family x:A⊢B(x)x:A \vdash B(x), indexed heterogeneous identity types of arity II are an inductive family of types

x¯:I→A,p:Id I,A(x¯),y¯:∏ i:IB(x¯(i))⊢hId I,A,B(x¯,p,y¯)\overline{x}:I \to A, p:\mathrm{Id}_{I, A}(\overline{x}), \overline{y}:\prod_{i:I} B(\overline{x}(i)) \vdash \mathrm{hId}_{I, A, B}(\overline{x}, p, \overline{y})

generated by the family of elements called “heterogeneous reflexivity”

x:A,y:B(x)⊢hrefl I,A,B(x,y):hId I,A,B(λt.x,refl I,A(x),λt.y)x:A, y:B(x) \vdash \mathrm{hrefl}_{I, A, B}(x, y):\mathrm{hId}_{I, A, B}(\lambda t.x, \mathrm{refl}_{I, A}(x), \lambda t.y)

where Id I,A(x¯)\mathrm{Id}_{I, A}(\overline{x}) denotes the identity type of arbitrary arity.

When the index type II is the booleans type 𝟚\mathbb{2}, the function x¯≡rec 𝟚,A(a,b)\overline{x} \equiv \mathrm{rec}_{\mathbb{2}, A}(a, b) is given by the recursion principle of the booleans type, and the function y¯≡ind 𝟚,λb.B(rec 𝟚,A(b))(y,z)\overline{y} \equiv \mathrm{ind}_{\mathbb{2}, \lambda b.B(\mathrm{rec}_{\mathbb{2}, A}(b))}(y, z) is given by the induction principle of the booleans type, then the binary type family

hId A(a,b,p,x,y)≡hId 𝟚,A(rec 𝟚,A(x,y),p,ind 𝟚,λb.B(rec 𝟚,A(b))(y,z))\mathrm{hId}_A(a, b, p, x, y) \equiv \mathrm{hId}_{\mathbb{2}, A}(\mathrm{rec}_{\mathbb{2}, A}(x, y), p, \mathrm{ind}_{\mathbb{2}, \lambda b.B(\mathrm{rec}_{\mathbb{2}, A}(b))}(y, z))

is precisely the usual indexed heterogeneous identity types as defined above, which indicates the heterogeneoud equality / identification of a family of two elements in a type family.

Indexed heterogeneous identity types of arity II are needed to define dependent function application to identifications of arity II, which are used in the induction principle of higher inductive types with path constructors of arity II, such as the walking identification.
