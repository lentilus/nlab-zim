Definition

A σ\sigma-frame is a σ \sigma -complete lattice (L,≤,⊥,∨,⊤,∧,⋁)(L, \leq, \bot, \vee, \top, \wedge, \Vee) such that for all elements a∈La \in L and sequences s:ℕ→Ls:\mathbb{N} \to L,

a∧⋁ n:ℕs(n)=⋁ n:ℕa∧s(n)a \wedge \Vee_{n:\mathbb{N}} s(n) = \Vee_{n:\mathbb{N}} a \wedge s(n)

Examples

  • The set of Sierpinski semi-decidable truth values is the initial σ\sigma-frame.

  • The limited principle of omniscience implies that the boolean domain is a σ\sigma-frame.

  • The limited principle of omniscience or the weak countable choice axiom AC ℕ,𝟚\mathrm{AC}_{\mathbb{N}, \mathbb{2}} implies that the set of semidecidable truth values is a σ\sigma-frame.

  • The intrinsic topology? on a set AA, which is the function set Σ A\Sigma^A

  • Malcev topologies for set AA, which are a σ\sigma-subframe of the intrinsic topology Σ A\Sigma^A.

  • Any frame is a σ\sigma-frame. In particular, the poset of truth values is a σ\sigma-frame.

Category of σ\sigma-frames

σFrm\sigma\mathrm{Frm} is the category whose objects are σ\sigma-frames and whose morphisms are σ\sigma-frame homomorphisms, that is lattice homomorphisms that preserve countable joins. σFrm\sigma\mathrm{Frm} is a replete subcategory of Pos and DistLat, and it is an algebraic category.

The opposite category of σFrm\sigma\mathrm{Frm} is the category σLoc\sigma\mathrm{Loc} of σ \sigma -locales; this is an example of the duality between space and quantity.
