braided object

A braided object in a monoidal category (C,⊗,I)(C,\otimes,I) is an object VV equipped with an invertible morphism σ:V⊗V→V⊗V\sigma : V\otimes V \to V\otimes V satisfying the Yang-Baxter equation

(σ⊗V)∘(V⊗σ)∘(σ⊗V)=(V⊗σ)∘(σ⊗V)∘(V⊗σ)(\sigma \otimes V) \circ (V \otimes \sigma) \circ (\sigma \otimes V) = (V \otimes \sigma) \circ (\sigma \otimes V) \circ (V \otimes \sigma)

More generally, if σ\sigma is not necessarily invertible but still satisfies the Yang-Baxter equation, then (V,σ)(V,\sigma) is called a pre-braided object.
