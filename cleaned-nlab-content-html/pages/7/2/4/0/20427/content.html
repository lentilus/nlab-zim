duality between heterotic and type II string theory

Idea

A duality in string theory relating heterotic string theory to type II string theory via KK-compactification on K3-surfaces. This is the archetypical example of string-string duality.

The non-perturbative enhancement of this is duality between heterotic string theory and M/F-theory.
