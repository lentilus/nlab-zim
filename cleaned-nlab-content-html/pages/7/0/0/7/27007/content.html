Idea

In probability theory, a martingale is a stochastic process where, intuitively, one takes averages over the data which are not yet known. As time progresses, one's knowledge increases, and so the “amount of averaging” decreases.

It is one of the most widely used concepts in probability theory.

Definition

Let (X,𝒜,p,(ℱ n))(X,\mathcal{A},p,(\mathcal{F}_n)) be a filtered probability space.

A martingale on (X,𝒜,p,(ℱ n))(X,\mathcal{A},p,(\mathcal{F}_n)) is a stochastic process (collection of random variables) f n:X→ℝf_n:X\to\mathbb{R} such that

  • For every nn, the function f nf_n is ℱ n\mathcal{F}_n-measurable (i.e. the process is adapted to the filtration:);
  • For each n≤mn\le m, the function f nf_n is a conditional expectation of f mf_m given ℱ n\mathcal{F}_n:
    f n=𝔼(f m|ℱ n). f_n \;=\; \mathbb{E}(f_m|\mathcal{F}_n) .

Similar definitions can be given for random variables with values in other spaces, for example, Banach spaces.

Variations

A submartingale on a filtered probability space (X,𝒜,p,(ℱ n))(X,\mathcal{A},p,(\mathcal{F}_n)) is an adapted stochastic process (f n)(f_n) satisfying

f n≤𝔼(f m|ℱ n) f_n \;\le\; \mathbb{E}(f_m|\mathcal{F}_n)

for each n≤mn\le m.

Similarly, a supermartingale on (X,𝒜,p,(ℱ n))(X,\mathcal{A},p,(\mathcal{F}_n)) is an adapted stochastic process (f n)(f_n) satisfying

f n≥𝔼(f m|ℱ n) f_n \;\ge\; \mathbb{E}(f_m|\mathcal{F}_n)

for each n≤mn\le m.

A backward martingale or inverse martingale can be seen as a martingale in reverse time. Explicitly, given a probability space (X,𝒜,p)(X,\mathcal{A},p) with a decreasing filtration (ℱ n)(\mathcal{F}_n) of sub-sigma-algebras (i.e. ℱ n⊇ℱ m\mathcal{F}_n\supseteq\mathcal{F}_m for n≤mn\le m), a backward martingale is an adapted process (f n)(f_n) satisfying

f m=𝔼(f n|ℱ m) f_m \;=\; \mathbb{E}(f_n|\mathcal{F}_m)

for each n≤mn\le m.
