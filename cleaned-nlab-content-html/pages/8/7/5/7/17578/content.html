Idea

An atomic topos is a topos ℰ\mathcal{E} where the global sections functor Γ:ℰ→Set\Gamma: \mathcal{E} \to Set is atomic. In the case where ℰ\mathcal{E} is a Grothendieck topos, there are some (arguably more explicit) alternative characterizations of atomic toposes, as in Theorem , which make it clearer why they are called “atomic”.

Definition

Recall that a geometric morphism ff is called atomic if its inverse image functor f *f^* is logical.

Definition

A topos over a base topos Γ:ℰ→𝒮\Gamma : \mathcal{E} \to \mathcal{S} is called an atomic topos if Γ\Gamma is atomic. Unless otherwise specified, the base topos will be taken to be SetSet.

Definition

A non-zero object AA of a topos ℰ\mathcal{E} is an atom if its only subobjects are AA and 00.

Theorem

Let ℰ\mathcal{E} be a Grothendieck topos. Then the following are equivalent:

  1. ℰ\mathcal{E} is an atomic topos.

  2. ℰ\mathcal{E} is the category of sheaves on an atomic site.

  3. The subobject lattice of every object of ℰ\mathcal{E} is a complete atomic Boolean algebra.

  4. ℰ\mathcal{E} has a small generating set of atoms.

  5. Every object of ℰ\mathcal{E} can be written as a disjoint union of atoms.

Proof

See Johnstone, C3.5.8 and Barr-Diaconescu, Theorem A.

Properties

Proposition

Let ℰ\mathcal{E} be an atomic topos. Then ℰ\mathcal{E} is Boolean.

This appears as one direction of (Johnstone, cor. C3.5.2).

Proof

If Γ *\Gamma^* is logical then it preserves the isomorphism *∐*≃Ω* \coprod * \simeq \Omega characterizing a Boolean topos.

Proposition

Let ℰ\mathcal{E} be a Boolean Grothendieck topos with enough points. Then ℰ\mathcal{E} is an atomic topos.

Proof

See (Johnstone, cor. C3.5.2)

Proposition

Atomic Grothendieck toposes Sh(𝒞,J at)Sh(\mathcal{C}, J_{at}) for (𝒞,J at)(\mathcal{C}, J_{at}) an atomic site are precisely the double negation subtoposes Sh ¬¬(Set 𝒞 op)Sh_{\neg\neg}(Set^{\mathcal{C}^{op}}) for a De Morgan presheaf topos Set 𝒞 opSet^{\mathcal{C}^{op}}.

Proof

For the argument see at atomic site.

Decomposition of atomic toposes

Atomic toposes decompose as disjoint unions of connected atomic toposes. Connected atomic toposes with a point are the classifying toposes of localic groups.

An example of a connected atomic topos without a point is given in (Johnstone, example D3.4.14).

Examples

  • A category of presheaves Set 𝒞 opSet^{\mathcal{C}^{op}} is atomic precisely iff 𝒞\mathcal{C} is a groupoid (cf. Barr-Diaconescu (1980)).

  • Another example of an atomic Grothendieck topos is the Schanuel topos. More generally, any category of G-sets is an atomic Grothendieck topos.
