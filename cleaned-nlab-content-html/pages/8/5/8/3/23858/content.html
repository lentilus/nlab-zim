Idea

A mathematical structure used to define the real numbers in Alfred Tarski’s axioms for the real numbers.

Definition

A Tarski group is a pointed commutative invertible semigroup (G,+,−,1)(G, +, -, 1) with a dense linear order <\lt such that 1<1+11 \lt 1 + 1, a<b+c+aa \lt b + c + a implies a<b+aa \lt b + a or a<c+aa \lt c + a, and a<ba \lt b implies c+a<c+bc + a \lt c + b.

As a result, every Tarski group is an abelian group with identity element 0≔1−10 \coloneqq 1 - 1, and a nontrivial ordered group.

Tarski’s axioms for the real numbers

Tarski’s axioms for the real numbers are as follows:

  • Axiom 5 says that ℝ\mathbb{R} is a commutative semigroup.

  • Axiom 6 with axiom 5 together say that ℝ\mathbb{R} is a commutative invertible semigroup.

  • Axiom 8 says that ℝ\mathbb{R} is a pointed set, which with axioms 5 and 6 imply that ℝ\mathbb{R} is an abelian group.

  • Axiom 1 says that ℝ\mathbb{R} has a connected relation <\lt.

  • Axiom 2 says that <\lt is an asymmetric relation and thus an irreflexive relation.

  • The fragment of Axiom 4 that only refers to singleton subsets says that <\lt is a comparison, making <\lt into a strict linear order. (the full axiom 4 is the Dedekind completeness condition).

  • Axiom 3 says that <\lt is a dense linear order.

  • Axiom 7 says that for all a,b,c,d∈Ga, b, c, d \in G, a+b<c+da + b \lt c + d implies that a<ca \lt c or b<db \lt d, which imply that ℝ\mathbb{R} is a linearly ordered group.

  • Axiom 9 says that 1<1+11 \lt 1 + 1, which indicates that ℝ\mathbb{R} is not trivial.

The archimedean field structure on the Dedekind-complete Tarski group

Let us denote the Dedekind-complete Tarski group as ℝ\mathbb{R}. There is an archimedean field structure on ℝ\mathbb{R}.

Proposition

ℝ\mathbb{R} is a Archimedean ordered abelian group.

Proof

Since ℝ\mathbb{R} is Dedekind-complete and a strictly ordered abelian group, ℝ\mathbb{R} is Archimedean, because the Dedekind-completion of any totally ordered abelian group with infinite elements or infinitesimals is not an abelian group, and the Dedekind-completion of any Archimedean ordered abelian group is still Archimedean.

Proposition

ℝ\mathbb{R} has a complete metric

Proof

Since ℝ\mathbb{R} is strictly ordered, it is a totally ordered abelian group. As a result, there exist maximum and minimum binary functions max:ℝ×ℝ→ℝ\max:\mathbb{R} \times \mathbb{R} \to \mathbb{R} and min:ℝ×ℝ→ℝ\min:\mathbb{R} \times \mathbb{R} \to \mathbb{R}, with the absolute value function defined as |x|=max(x,−x)\vert x \vert = \max(x, -x).

Since ℝ\mathbb{R} is Dedekind-complete, Archimedean, and a totally ordered abelian group, ℝ\mathbb{R} is a metric space with respect to the absolute value |x|\vert x \vert and thus a Hausdorff space, and every Cauchy net in ℝ\mathbb{R} converges to a unique element of ℝ\mathbb{R}, and thus the absolute value |x|\vert x \vert is a complete metric on ℝ\mathbb{R}.

Proposition

ℚ\mathbb{Q} embeds in ℝ\mathbb{R}.

Proof

Since ℝ\mathbb{R} is an abelian group, it is a ℤ\mathbb{Z}-module, and since ℝ\mathbb{R} is totally ordered, it is a torsion-free module and thus a torsion-free abelian group, which means that the integers ℤ\mathbb{Z} embed in ℝ\mathbb{R}, with injective group homomorphism f:ℤ→ℝf:\mathbb{Z} \to \mathbb{R} where f(0)=0f(0) = 0 and f(1)=1f(1) = 1. As a result, for every integer a∈ℤa \in \mathbb{Z} and b∈ℤb \in \mathbb{Z} the affine functions x↦ax+bx \mapsto a x + b are well defined in ℝ\mathbb{R}.

Since ℝ\mathbb{R} is Dedekind-complete, Archimedean, and a totally ordered abelian group, any closed interval [a,b][a, b] on ℝ\mathbb{R} is compact and conencted. Since ℝ\mathbb{R} is also a complete metric space, the intermediate value theorem is satisfied for every function from a closed interval [a,b][a, b] to ℝ\mathbb{R}. Because x↦ax+bx \mapsto a x + b are monotonic for a>0a \gt 0, and for a<0a \lt 0 the function is just the negation of a monotonic function, x↦ax+bx \mapsto a x + b have a root? for |a|>0\vert a \vert \gt 0. Thus ℝ\mathbb{R} is a divisible group and a ℚ\mathbb{Q}-vector space, with an injective group homomorphism f:ℚ→ℝf:\mathbb{Q} \to \mathbb{R} where f(0)=0f(0) = 0 and f(1)=1f(1) = 1, and ℚ\mathbb{Q} embeds in ℝ\mathbb{R}.

Proposition

ℝ\mathbb{R} is a commutative ring.

Proof

Since every Cauchy net in ℝ\mathbb{R} converges to a unique element of ℝ\mathbb{R}, for every directed set AA and Cauchy net (a i) i∈A(a_i)_{i \in A} in the rational numbers, there exists a Cauchy net of linear functions (f i) i∈A(f_i)_{i \in A} defined as f i(x)=a ixf_i(x) = a_i x. The limit of the Cauchy net lim i∈A(f i) i\lim_{i \in A} (f_i)_i exists and is a unique function g(x)=lim i∈A(a i) ixg(x) = \lim_{i \in A} (a_i)_i x. Since every real number is the limit of a Cauchy net of rational numbers, there is an ℝ\mathbb{R}-action μ:ℝ→(ℝ→ℝ)\mu:\mathbb{R} \to (\mathbb{R} \to \mathbb{R}) which takes a real number rr to the linear function x↦rxx \mapsto r x, with α(1)=x↦x\alpha(1) = x \mapsto x being the identity function. The uncurrying of α\alpha leads to a bilinear function (−)(−):ℝ×ℝ→ℝ(-)(-):\mathbb{R} \times \mathbb{R} \to \mathbb{R} called multiplication of the real numbers, defined on the entire domain of the binary function. Since linear functions in the function space with function composition? and the identity function is a commutative monoid, ℝ\mathbb{R} with multiplication and the multiplicative identity element 11 is also commutative monoid, which means that ℝ\mathbb{R} is a commutative ring.

Proposition

ℝ\mathbb{R} is a field

Proof

Since ℝ\mathbb{R} is a commutative ring, power series are well defined, and because all Cauchy nets converge in ℝ\mathbb{R}, all Cauchy sequences and all Cauchy power series converge in ℝ\mathbb{R}. In particular, every geometric series is a Cauchy power series and the limit of the geometric series

and
