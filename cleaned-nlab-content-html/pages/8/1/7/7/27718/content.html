Idea

In dependent type theory with explicit parametricity and bridge types, displayed coinductive types are a generalization of coinductive types where the output of a method is a higher-dimensional bridge cube version of itself, similarly to how a higher inductive type has constructors whose output is a higher-dimensional version of itself.

Examples

  • In parametric type theory with unary bridge types (Br A(x)) x:A(\mathrm{Br}_A(x))_{x:A}, the type of augmented semi-simplicial types U Δ α+ opU^{\Delta_{\alpha+}^\op} in a type universe UU is a displayed coinductive type cogenerated by

    • a function Z +:U Δ α+ op→UZ^+:U^{\Delta_{\alpha+}^\op} \to U and

    • a dependent function
