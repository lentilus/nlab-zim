Definition

Given a commutative ring RR, RR is reduced or has a trivial nilradical if x⋅x=0x \cdot x = 0 implies that x=0x = 0 for all x∈Rx \in R.

Theorem

For every natural number nn, x n+1=0x^{n + 1} = 0 implies that x=0x = 0 for all x∈Rx \in R.

Proof

Let the function f:ℕ→ℕf:\mathbb{N} \to \mathbb{N} be defined as the ceiling of half of nn, f(n)≔⌈n/2⌉f(n) \coloneqq \lceil n/2 \rceil. Then x n+1=0x^{n + 1} = 0 implies that x f(n+1)=0x^{f(n + 1)} = 0, and for every natural number nn, the (n+1)(n + 1)-th iteration of the function ff evaluated at n+1n + 1 is always equal to 11, f n+1(n+1)=1f^{n + 1}(n + 1) = 1, thus resulting in x f n+1(n+1)=x=0x^{f^{n + 1}(n + 1)} = x = 0. Thus, the nilradical of RR is trivial.

As a result, the theory of a reduced ring is a coherent theory.

Properties

  • Every integral domain is a reduced ring. Thus, every field is a reduced ring.

  • An example of a reduced ring which is not an integral domain is the quotient ring R[x,y]/(x⋅y)R[x, y]/(x \cdot y).

  • Given a square-free integer nn, the integers modulo n ℤ/nℤ\mathbb{Z}/n\mathbb{Z} is a reduced ring. Since for every integer nn, ℤ/nℤ\mathbb{Z}/n\mathbb{Z} is a prefield ring, ℤ/nℤ\mathbb{Z}/n\mathbb{Z} is an integral domain and thus a field if and only if nn is a prime number.

  • Given a discrete field FF, let F¯\overline{F} denote its algebraic closure. Given a square-free polynomial q∈F¯[x]q \in \overline{F}[x], the quotient ring F¯[x]/qF¯[x]\overline{F}[x]/q\overline{F}[x] is a reduced ring. Since for every polynomial q∈F¯[x]q \in \overline{F}[x], F¯[x]/qF¯[x]\overline{F}[x]/q\overline{F}[x] is a prefield ring, F¯[x]/qF¯[x]\overline{F}[x]/q\overline{F}[x] is an integral domain and thus a field if and only if qq is a prime polynomial in F¯[x]\overline{F}[x], a monic polynomial of degree one; the resulting quotient ring is equivalent to F¯\overline{F}.
