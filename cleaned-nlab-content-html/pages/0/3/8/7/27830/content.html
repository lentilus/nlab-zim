confluent (∞,1)-category

Definition

A quasicategory CC is confluent if for every cospan Q:Λ 0 2→CQ\colon\Lambda^2_0\to C the quasicategory I Q/I_{Q/} of cocones under QQ is weakly contractible.

Properties

If CC has pushouts, then CC is confluent because the quasicategory of cocones has an initial object.

A quasicategory CC is confluent if and only if for every morphism f:A→Bf\colon A\to B, the induced functor f *:C B/→C A/f^*\colon C_{B/}\to C_{A/} is a final functor.

If π:T→B\pi\colon T\to B is a left fibration and BB is confluent, then so is TT.

Theorem

(Sattler & Wärn 2025) A quasicategory CC is confluent if and only if CC-indexed colimits commute with pullbacks in the quasicategory of ∞-groupoids.

A quasicategory is filtered if and only if it is confluent and weakly contractible.
