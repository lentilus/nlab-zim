Idea

In material set theory, sets and elements are the same thing, so unordered pairs and pair sets are the same thing. However, in other foundations of mathematics, sets and elements are not the same thing, so an unordered pair is an element, while a pair set is a set.

 Definition

In material set theory

If AA is a set and xx and yy are elements of AA, then the pair set {x,y}\{x,y\} is a subset of AA such that for all elements for which z∈{x,y}z \in \{x,y\} holds, z=xz = x or z=yz = y. In material set theory, these are also called unordered pairs.

In material set theory, we may apply this when xx and yy are not previously given as elements of any set AA. In that case, the existence of the unordered pair is given by the axiom of pairing.

In structural set theory

If AA is a set and xx and yy are elements of AA, then the pair set {x,y}\{x,y\} is a subset of AA with injection i:{x,y}↪Ai:\{x,y\} \hookrightarrow A such that for all elements z∈{x,y}z \in \{x,y\}, i(z)=xi(z) = x or i(z)=yi(z) = y, and for all other sets BB with injection j:B↪Aj:B \hookrightarrow A such that for all elements w∈Bw \in B, i(w)=xi(w) = x or i(w)=yi(w) = y, there is an injection k:B↪{x,y}k:B \hookrightarrow \{x,y\} such that for all elements w∈Bw \in B, i(k(w))=j(w)i(k(w)) = j(w).

 Properties

The pair set {x,x}={x}\{x,x\} = \{x\} is a singleton.
