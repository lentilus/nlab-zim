 Idea

De Bruijn indices are used to represent terms in lambda calculus and type theory without naming bound variables.

Usually in informal mathematical language, an expression involving a lambda is written out as λx.ϕ(x)\lambda x.\phi(x). However, this involves the use of bound variables, which are hard to deal with when formalizing substitution of variables; in addition, the statements λx.ϕ(x)\lambda x.\phi(x) and λy.ϕ(y)\lambda y.\phi(y) refer to the same thing. De Bruijn indices involve the use natural numbers instead of bound variables; both λx.ϕ(x)\lambda x.\phi(x) and λy.ϕ(y)\lambda y.\phi(y) would be written as λϕ(0̲)\lambda \phi(\underline{0}) when using De Bruijn indices, and λx.λy.ϕ(x,y)\lambda x.\lambda y.\phi(x, y) would be written as λλϕ(1̲,0̲)\lambda \lambda \phi(\underline{1}, \underline{0}). A statement like xλx.ϕ(x)x \lambda x.\phi(x) where xx is both a bound variable and a free variable would be written as 1̲λϕ(0̲)\underline{1} \lambda \phi(\underline{0}) using de Bruijn indices.
