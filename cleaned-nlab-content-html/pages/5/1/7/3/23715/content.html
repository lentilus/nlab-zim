In Heyting fields

Given a Heyting field FF, let us define the type of all terms in FF apart from 0:

F #0≔{a∈F|a#0}F_{#0} \coloneqq \{a \in F \vert a # 0\}

The reciprocal or reciprocal function is a partial function 1−:F #0→F\frac{1}{-}:F_{#0} \to F such that for all a∈F #0a \in F_{#0} we have a⋅1a=1a \cdot \frac{1}{a} = 1 and 1a⋅a=1\frac{1}{a} \cdot a = 1

In a discrete field, the reciprocal is a function f:F→F+1f:F \to F + 1 defined as

f(x)≔1xf(x) \coloneqq \frac{1}{x}

for x≠0x \neq 0 and

f(x)≔⊥f(x) \coloneqq \bot

for x=0x = 0, where ⊥∈1\bot \in 1. This is because for a discrete field FF, the set F #0≃F ≠0F_{#0} \simeq F_{\neq 0} is a decidable subset of FF.
