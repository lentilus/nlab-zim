Idea

Propositional resizing is an axiom often assumed in homotopy type theory that states that all mere propositions are small. This is a form of impredicativity since it implies propositional impredicativity and thus power sets for successor universes.

Despite that, propositional resizing is a relatively weak axiom, for instance it is implied by the law of excluded middle, which states that the small type 22 classifies all propositions. However, it is independent of the other basic axioms of homotopy type theory.

Definition

Propositional resizing can be defined for individual type universes (Gylterud, Stenholm, & Veltri 2020) or for the type theory as a whole (HoTT Book).

In dependent type theory where for every type AA, there is a type universe UU such that AA is essentially UU-small, one can define propositional resizing for the entire type theory: a universe VV satisfies UU-propositional resizing if every proposition in VV is essentially U U -small. Propositional resizing for the entire dependent type theory then is the axiom that all universes VV satisfy UU-resizing for all universes UU.

If the universe VV additionally contains a type classifying all UU-small types, then the type Prop U\mathrm{Prop}_U is a VV-small type of all VV-small propositions, making the universe VV satisfy propositional impredicativity. In particular, for a natural numbers-indexed universe hierarchy such as those found in the HoTT book and proof assistants like Lean, Agda, and Rocq, if propositional resizing holds, then every successor universe U i+1U_{i + 1} is a propositionally impredicative universe, while only the base universe U 0U_0 is a predicative universe.

In dependent type theory with a single type judgment, a type universe UU satisfies propositional resizing if every proposition PP in the dependent type theory is essentially UU-small. The type Prop U\mathrm{Prop}_U is a type of all propositions, making the whole dependent type theory satisfy propositional impredicativity.

Relation to the axiom schema of separation

Propositional resizing for a type universe UU is equivalent in strength to the axiom schema of separation for UU.

The axiom schema of separation for a type universe UU in dependent type theory states that for all UU-small types A:UA:U and families of possibly large h-propositions (B(x)) x:A(B(x))_{x:A}, the dependent sum type ∑ x:AB(x)\sum_{x:A} B(x) is essentially U U -small.

Propositional resizing is equivalent to the case of the axiom schema of separation where AA is the unit type 11 by large recursion of the unit type, or where (B(x)) x:A(B(x))_{x:A} is a constant family of h-propositions. On the other hand, if propositional resizing holds, then every h-proposition is UU-small and so the dependent sum type ∑ x:AB(x)\sum_{x:A} B(x) is essentially U U -small by definition.

Note that in either case, the type of all propositions Prop U\mathrm{Prop}_U is still UU-large, meaning that UU is still predicative as a universe.
