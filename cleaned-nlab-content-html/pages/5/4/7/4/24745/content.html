Definition

In a dependent type theory with function types, dependent sum types, and identity types, the fiber (or “fiber type”) of a function f:A→Bf:A \to B over a term b:Bb:B is defined to be the type

fiber A,B(f,b)≔∑ a:A(f(a)=b) \mathrm{fiber}_{A, B}(f, b) \;\coloneqq\; \sum_{a : A} \big( f(a) = b \big)

hence the dependent sum over AA of the identity type on BB with f(a)f(a) and bb substituted.

Rules for fiber types

If the dependent type theory does not have dependent sum types, it is still possible to define fiber types by adding the formation, introduction, elimination, computation, and uniqueness rules for fiber types
