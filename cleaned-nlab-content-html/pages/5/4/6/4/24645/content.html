Definition

In homotopy type theory a preallegory is a dagger precategory CC such that

  • for each object a:Ob(C)a:Ob(C) and b:Ob(C)b:Ob(C) there is a function

    (−)∧ a,b(−):Mor C(a,b)×Mor C(a,b)→Mor C(a,b)(-)\wedge_{a, b}(-):Mor_C(a, b) \times Mor_C(a, b) \to Mor_C(a, b)

    such that for each morphism f:Mor C(a,b)f:Mor_C(a, b), g:Mor C(a,b)g:Mor_C(a, b), and h:Mor C(a,b)h:Mor_C(a, b) there are identifications

    assoc(a,b,f,g,h):f∧ a,b(g∧ a,bh)=(f∧ a,bg)∧ a,bh\mathrm{assoc}(a, b, f, g, h):f \wedge_{a, b} (g \wedge_{a, b} h) = (f \wedge_{a, b} g) \wedge_{a, b} h
    comm(a,b,f,g):f∧ a,bg=g∧ a,bf\mathrm{comm}(a, b, f, g):f \wedge_{a, b} g = g \wedge_{a, b} f
    idem(a,b,f):f∧ a,bf=f\mathrm{idem}(a, b, f): f \wedge_{a, b} f = f

  • for each object a:Ob(C)a:Ob(C) and b:Ob(C)b:Ob(C) and morphism f:Mor C(a,b)f:Mor_C(a, b) and g:Mor C(a,b)g:Mor_C(a, b) there is a function

    monotone(a,b,f,g):(f∧ a,bg=f)→(f † a,b∧ b,ag † a,b=f † a,b)\mathrm{monotone}(a, b, f, g): (f \wedge_{a, b} g = f) \to (f^{\dagger_{a, b}} \wedge_{b, a} g^{\dagger_{a, b}} = f^{\dagger_{a, b}})

  • for each object a:Ob(C)a:Ob(C), b:Ob(C)b:Ob(C), and c:Ob(C)c:Ob(C) and morphism f:Mor C(a,b)f:Mor_C(a, b), g:Mor C(b,c)g:Mor_C(b, c), and h:Mor C(a,c)h:Mor_C(a, c), there is an identification

    modular(a,b,c,f,g,h):((g∘ a,b,cf)∧ a,ch)∧ a,c(g∘ a,b,c(f∧ a,b(g † b,c∘ a,c,bh)))=(g∘ a,b,cf)∧ a,ch\mathrm{modular}(a, b, c, f, g, h):\left((g \circ_{a, b, c} f) \wedge_{a, c} h\right) \wedge_{a, c} \left(g \circ_{a, b, c} (f \wedge_{a, b} (g^{\dagger_{b, c}} \circ_{a, c, b} h))\right) = (g \circ_{a, b, c} f) \wedge_{a, c} h

Examples

  • For every type universe 𝒰\mathcal{U} the precategory Rel 𝒰\mathrm{Rel}_\mathcal{U} of 𝒰\mathcal{U}-small sets and locally 𝒰\mathcal{U}-small propositional-valued relations is a preallegory.
