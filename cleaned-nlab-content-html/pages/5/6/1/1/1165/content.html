orbit groupoid

If a group GG acts on a groupoid Γ\Gamma, then there is an orbit groupoid Γ//G\Gamma /\! / G which is a groupoid with trivial GG-action and with a GG-morphism Γ→Γ//G\Gamma \to \Gamma /\! / G universal for GG-morphisms to groupoids with trivial GG-action. So in principle Γ//G\Gamma /\! / G is obtained from Γ\Gamma by identifying g.γg.\gamma and γ\gamma for all g∈Gg \in G, γ∈Γ\gamma \in \Gamma.

Note that if a group GG acts on a space XX then it has an induced action on the fundamental groupoid Π 1X\Pi_1 X, and so there is an induced morphism

α:Π 1X//G→Π 1(X/G).\alpha: \Pi_1 X /\! / G \to \Pi_1 (X/G).

So there is interest in when this morphism is an isomorphism.

α\alpha is an isomorphism if XX is Hausdorff, has a universal cover, and the action of GG on XX is discontinuous.

This allows some calculation of the fundamental groups of orbit spaces.
