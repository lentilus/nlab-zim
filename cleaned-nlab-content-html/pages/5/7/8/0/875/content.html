Definition

A (binary) relation ∼\sim on a set AA is reflexive if every element of AA is related to itself:

∀(x:A),x∼x\forall (x: A),\; x \sim x

In the language of the 22-poset Rel of sets and relations, a relation R:A→AR: A \to A is reflexive if it contains the identity relation on AA:

id A⊆R\id_A \subseteq R

Relation to graphs

A set with a reflexive relation is the same as a loop digraph (V,E,s:E→V,t:E→V)(V, E, s:E \to V, t:E \to V) with function refl:V→Erefl:V \to E such that

  • for every a∈Va \in V, s(refl(a))= Vas(refl(a)) =_V a
  • for every a∈Va \in V, t(refl(a))= Vat(refl(a)) =_V a

Examples

  • In dependent type theory, the binary relation isContr(Id A(x,y))\mathrm{isContr}(\mathrm{Id}_A(x, y)) which says whether there is a unique identification between x:Ax:A and y:Ay:A is only a reflexive relation for h-sets by axiom K.
