Idea

The moduli stack of formal groups ℳ FG\mathcal{M}_{FG} admits a natural stratification whose open strata are labeled by a natural number called the height of formal groups.

The complex oriented cohomology theories associated to these formal groups by the Landweber exact functor theorem accordingly also inherit such an integer label, called chromatic filtration. Studying this is the topic of chromatic homotopy theory.

Definition

Let RR be a commutative ring and fix

f(x,y)∈R[[x,y]] f(x,y) \in R [ [ x,y ] ]

a formal group law over RR.

Definition

For every n∈ℕn \in \mathbb{N} the nn-series of ff

[n](t)∈R[[t]] [n](t) \in R[ [ t ] ]

is defined recursively by

  1. if n=0n = 0 then [n](t)=0[n](t) = 0;

  2. if n>0n \gt 0 then [n](t)=f([n−1](t),t)[n](t) = f([n-1](t),t).

Now fix p∈ℕp \in \mathbb{N} a prime number,

Definition

Write v nv_n for the coefficient of t p nt^{p^n} in the pp-series [p][p] of ff.

Definition

Say that ff

  • has height ≥n\geq n if v i=0v_i = 0 for i<ni \lt n;

  • has height exactly nn if it has height ≥n\geq n and v n∈Rv_n \in R is invertible.

For instance (Lurie 10, lecture 12, def. 13).

Examples

Example

For f(x,y)=x+y+xyf(x,y) = x + y + x y the formal multiplicative group the nn-series is

[n](t)=(1+t) n−1. [n](t) = (1+t)^n - 1 \,.

If p=0p = 0 in RR then

[p](t)=(1+t) p−1=t p [p](t) = (1+t)^p - 1 = t^p

and thus ff has height exactly 1.

For instance (Lurie 10, lecture 12, example 16).

Example

An elliptic curve over a field of positive characteristic whose formal group law has height equal to 2 is called a supersingular elliptic curve. Otherwise the height equals 1 and the elliptic curve is called ordinary.
