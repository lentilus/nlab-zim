Idea

The representable and corepresentable functor theorems are simple consequences of the general adjoint functor theorem and the following observations:

  • Suppose CC is a complete category. A functor F:C op→SetF: C^{op}\to Set is representable if and only if it has a left adjoint LL. In this case, L({*})=XL(\{\ast\})=X is the representing object. More generally, L(S)=X SL(S)=X^S is the product of SS copies of XX, which exists.

  • Suppose CC is a cocomplete category. A functor F:C→SetF:C\to Set is corepresentable if and only if it has a left adjoint LL. In this case, L({*})=XL(\{\ast\})=X is the corepresenting object. More generally, L(S)=∐ SXL(S)=\coprod_S X is the coproduct of SS copies of XX, which exists.

Statement

The representable functor theorem states that:

  • A presheaf C op→SetC^{op} \to Set on a cocomplete category CC is representable, i.e., of the form C(−,c)C({-}, c) for some object c∈Cc \in C if and only if it sends colimits in CC to limits in SetSet and has a solution set.

The latter condition means the following: there is a set II, an II-indexed family of objects X i∈CX_i\in C, and an II-indexed family of elements f i∈F(X i)f_i\in F(X_i) such that for every object Y∈CY\in C and h∈F(Y)h\in F(Y) there is k∈Ik\in I and t:Y→X it\colon Y\to X_i such that h=F(t)(f i)h=F(t)(f_i).

Dually, the corepresentable functor theorem states that:

  • A copresheaf C→SetC \to Set on a complete category CC is corepresentable, i.e., of the form C(c,−)C(c, {-}) for some object c∈Cc \in C if and only if it is continuous and has a solution set.

The latter condition means the following: there is a set II, an II-indexed family of objects X i∈CX_i\in C, and an II-indexed family of elements f i∈F(X i)f_i\in F(X_i) such that for every object Y∈CY\in C and h∈F(Y)h\in F(Y) there is k∈Ik\in I and t:X i→Yt\colon X_i\to Y such that h=F(t)(f i)h=F(t)(f_i).

Related facts

As representable functors are closely connected to adjoint functors, this theorem is essentially equivalent to the adjoint functor theorem and to theorems guaranteeing the existence of limits.

Specifically, assuming that CC is copowered over Set (in particular, this is true if CC is cocomplete), a functor C→SetC\to Set is a right adjoint functor if and only if it is representable, in which case the left adjoint functor Set→CSet\to C sends the singleton set to the representing object, and more generally a set XX to the copower of XX with the representing object.
