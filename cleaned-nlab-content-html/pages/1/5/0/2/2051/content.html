Definition

In sets

Definition

A discrete group GG is called a Hopfian group if every surjective endomorphism ϕ:G→G\phi \colon G\to G is an isomorphism.

Dually, it is called coHopfian if any injective endomorphism of GG is an isomorphism.

In concrete categories

As the epimorphisms and monomorphisms in Grp are precisely the surjections and injections (see epimorphisms of groups are surjective), the definition generalises immediately to that of a Hopfian object in any category. In other words, we could define an object XX to be Hopfian if every epimorphic endomorphism is an isomorphism (cf. Dedekind finite object).

Whatever that generalization is worth, much of the literature (such as Varadarajan 1992) adopts the more concrete notion:

Definition

Given a concrete category U:C→SetU \colon C \to Set with UU a faithful functor, say that an object XX of CC is Hopfian if every morphism ϕ:X→X\phi \colon X \to X in CC with U(ϕ)U(\phi) surjective is an isomorphism.

Remark

Notice that if UU if faithful, then ϕ\phi is epimorpic if U(ϕ)U(\phi) is surjective.

Remark

For monadic functors U:C→SetU \colon C \to Set, this surjectivity assumption is the same as the assumption that ϕ\phi is a regular epimorphism.

Of course there is a dual notion of being co-Hopfian; here the hypothesis that U(ϕ)U(\phi) is injective frequently coincides simply with ϕ\phi being monomorphic – certainly that is true if UU preserves finite limits (which is frequently the case in application).

Examples

Example

Clearly all finite groups are both Hopfian and coHopfian.

Example

Using Nielsen’s method, one can show that every finitely generated free group and the union of any ascending chain of such free groups (for example, ℚ\mathbb{Q}) are Hopfian.
