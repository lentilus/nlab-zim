Definition

A protoring MM is an archimedean protoring if for all terms a,b,c,d∈Ma, b, c, d \in M, c<dc \lt d implies that there exists a positive natural number n∈ℕ +n \in \mathbb{N}_+ such that

b+∑ i=1 nc<a+∑ i=1 ndb + \sum_{i=1}^n c \lt a + \sum_{i=1}^n d

where

∑ i=1 (−)(−):ℕ +×M→M\sum_{i=1}^{(-)} (-):\mathbb{N}_+ \times M \to M

is the canonical left non-unital ℕ +\mathbb{N}_+-action for commutative semigroups defined inductively by

∑ i=1 1c≔c\sum_{i=1}^{1} c \coloneqq c
∑ i=1 n+1c≔c+∑ i=1 n\sum_{i=1}^{n + 1} c \coloneqq c + \sum_{i=1}^{n}
