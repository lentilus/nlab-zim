decomposition theory

Let 𝒫\mathcal{P} be a strictly full subcategory of a Grothendieck category 𝒞\mathcal{C} and SS a set. A predecomposition theory is a function which to each MM in 𝒫\mathcal{P} gives a subset Γ(M)⊂S\Gamma(M)\subset S such that

(i) Γ(M)=0\Gamma(M) = 0 iff M=0M = 0

(ii) For any exact sequence

0→M′→M→M″→0 0\to M' \to M\to M'' \to 0

in 𝒞\mathcal{C}, with M∈𝒫M\in \mathcal{P}, Γ(M′)⊂Γ(M)⊂Γ(M′)∪Γ(M″)\Gamma(M')\subset \Gamma(M) \subset \Gamma(M')\cup\Gamma(M'').

(iii) If M=∑ iM iM = \sum_i M_i then Γ(M)=∪ iΓ(M i)\Gamma(M)=\cup_i \Gamma(M_i).

(iv) If M′M' is an essential subobject of M∈Ob(𝒫)M\in Ob(\mathcal{P}), then Γ(M′)=Γ(M)\Gamma(M') = \Gamma(M). One often writes, by abuse of notation, Γ:𝒫→S\Gamma : \mathcal{P}\to S. For any M∈𝒫M\in\mathcal{P}, the elements of Γ(M)\Gamma(M) are called Γ\Gamma-associates of MM.

A class of examples are spectral predecomposition theories.

An object M∈Ob(𝒫)M\in Ob(\mathcal{P}) is said to be Γ\Gamma-coirreducible if Γ(M)\Gamma(M) contains exactly one element.

A subobject M′⊂MM'\subset M is Γ\Gamma-irreducible if M′/MM'/M is Γ\Gamma-coirreducible.

A predecomposition theory Γ:𝒫→M\Gamma:\mathcal{P}\to M is caleld a decomposition theory if any subobject M′M' of an object M∈𝒫M\in\mathcal{P} has a Γ\Gamma-decomposition, that is the set of subobjects {M i} i∈I\{M_i\}_{i\in I}, M i⊂MM_i\subset M such that

(D1) ∩ i∈IM i=M′\cap_{i\in I} M_i = M'

(D2) for each ii, M iM_i is a Γ\Gamma-irreducible subobject

(D3) Γ(M/M i)∩Γ(M/M j)=∅\Gamma(M/M_i) \cap \Gamma(M/M_j) = \emptyset if i≠ji\neq j

(D4) Γ(M i/M′)=Γ(M/M′)−Γ(M/M i)\Gamma(M_i/M') = \Gamma(M/M')-\Gamma(M/M_i)

(D5) Γ(M/M′)=∪ iΓ(M/M i)\Gamma(M/M') = \cup_i \Gamma(M/M_i)

Examples include primary decomposition theory, Lesieur-Croisot tertiary decomposition theory, Bourbaki’s 𝒫\mathcal{P}-primary decomposition theories…
