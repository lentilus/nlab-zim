Bruck-Toyoda theorem

A binary algebraic structure (A,⋅)(A,\cdot) is medial if for all a,b,c,d∈Aa,b,c,d\in A (a⋅b)⋅(c⋅d)=(a⋅c)⋅(b⋅d)(a\cdot b)\cdot(c\cdot d) = (a\cdot c)\cdot (b\cdot d). This law is quite close to commutativity: for example, if (A,⋅)(A,\cdot) has a unit element (is a unital magma), then by Eckmann-Hilton argument, it is an Abelian monoid. Without two-sided unit element, the connection with Abelian groups is somewhat more intricate

(Bruck-Toyoda theorem) A quasigroup (A,⋅)(A,\cdot) is medial iff there is an Abelian group structure (A,+)(A,+) on AA and mutually commuting group automorphisms ϕ,ψ:A→A\phi,\psi:A\to A and an element h∈Ah\in A such that

a⋅b=ϕ(a)+ψ(b)+h a\cdot b = \phi(a)+\psi(b)+h

An element aa in a magma (A,⋅)(A,\cdot) is left regular if the left multiplication L aL_a by aa is bijective and right regular if the right multiplication R aR_a is bijective. The Bruck-Toyoda theorem is a direct corollary of a more general statement about (nonunital in general) magmas:

Theorem.
