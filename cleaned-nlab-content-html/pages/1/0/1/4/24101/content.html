Definition

In measure theory, a content on a distributive lattice (L,≤,⊥,∨,⊤,∧)(L, \leq, \bot, \vee, \top, \wedge) is a function

μ:L⟶[0,∞] \mu \,\colon\, L \longrightarrow [0, \infty]

to the non-negative lower reals satisfying:

  1. strictness, the bottom element is sent to zero:

    μ(⊥)=0\mu(\bot) = 0

  2. additivity:

    ∀ a,b∈L:(a∧b=⊥)⇒(μ(a∨b)=μ(a)+μ(b)). \forall_{a,b\in L} \;\;:\;\; (a \wedge b = \bot) \implies \big( \mu(a \vee b) = \mu(a) + \mu(b) \big) \mathrlap{\,.}

A content that moreover satisfies the conditions

  1. modularity:

    μ(a)+μ(b)=μ(a∨b)+μ(a∧b)\mu(a) + \mu(b) = \mu(a \vee b) + \mu(a \wedge b)

  2. monotonicity:

    (a≤b)⇒(μ(a)≤μ(b))(a \leq b) \Rightarrow \big(\mu(a) \leq \mu(b)\big)

is called a valuation.
