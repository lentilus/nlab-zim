 Idea

In linear logic and affine logic, the ??-modality or the exponential disjunction is the de Morgan dual of the !-modality.

Examples

Antithesis interpretation

In the antithesis interpretation of affine logic into impredicative constructive mathematics, given the set of truth values Ω\Omega, one can define a set of affine propositions by the set

Ω ±≔{(P +,P −)∈Ω×Ω⊢¬(P +∧P −)}\Omega_\pm \coloneqq \{(P^+, P^-) \in \Omega \times \Omega \vdash \neg (P^+ \wedge P^-)\}

The ?-modality is a function ?:Ω ±→Ω ±?:\Omega_\pm \to \Omega_\pm is defined for each affine proposition (P +,P −)∈Ω ±(P^+, P^-) \in \Omega_\pm by

?(P +,P −)≔(¬P −,P −)?(P^+, P^-) \coloneqq (\neg P^-, P^-)

Theorem

The ?-modality is equal to the multiplicative disjunction of (P +,P −)(P^+, P^-) with itself

!(P +,P −)=(P +,P −)⅋(P +,P −)!(P^+, P^-) = (P^+, P^-) \invamp (P^+, P^-)

Proof

The multiplicative disjunction is given by

(P +,P −)⅋(P +,P −)=((P −⇒P +)∧(P −⇒P +),P −∧P −)(P^+, P^-) \invamp (P^+, P^-) = ((P^- \Rightarrow P^+) \wedge (P^- \Rightarrow P^+), P^- \wedge P^-)

Given two propositions P +P^+ and P −P^- such that ¬(P +∧P −)\neg (P^+ \wedge P^-), we have ¬P +=P −⇒P +\neg P^+ = P^- \Rightarrow P^+. Since intuitionistic conjunction is idempotent, we have

(P +,P −)⅋(P +,P −)=((P −⇒P +)∧(P −⇒P +),P −∧P −)=(¬P −∧¬P −,P −∧P −)=(¬P −,P −)=?(P +,P −)(P^+, P^-) \invamp (P^+, P^-) = ((P^- \Rightarrow P^+) \wedge (P^- \Rightarrow P^+), P^- \wedge P^-) = (\neg P^- \wedge \neg P^-, P^- \wedge P^-) = (\neg P^-, P^-) = ?(P^+, P^-)
