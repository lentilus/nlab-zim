Idea

Cup-ii products extend cup products.

They can be used to define Steenrod squares in the same manner as ordinary cup products can be used to define the square of a cohomology class.

Definition

Given a simplicial set XX and i≥0i\ge0, we define the cup-ii product as the map on simplicial cochains on XX with coefficients in Z/2\mathbf{Z}/2 induced by the map on simplicial chains

Δ i:C(X,Z/2)→C(X,Z/2)⊗C(X,Z/2),\Delta_i: C(X,\mathbf{Z}/2) \to C(X,\mathbf{Z}/2)\otimes C(X,\mathbf{Z}/2),

where Δ i\Delta_i evaluate on an nn-simplex x∈X nx\in X_n is 0 if i>ni\gt n and

∑ Ud U 0(x)⊗d U 1(x),\sum_U d_{U^0}(x)\otimes d_{U^1}(x),

where U⊂{0,…,n}U\subset \{0,\ldots,n\} has cardinality n−in-i and

U k={u∈U∣r(u)+k=u(mod2)},U^k=\{u\in U\mid r(u)+k=u \pmod2\},

where r(u)=#{v∈U∣v≤u}r(u)=\#\{v\in U\mid v\le u\}.

Thus, we have

(x∪ iy)(c)=(x⊗y)(Δ i(c)).(x \cup_i y)(c) = (x\otimes y)(\Delta_i(c)).

Properties

We have

Sq i(x)=x∪ ix,Sq^i(x) = x \cup_i x,

where Sq iSq^i denotes the iith Steenrod square.
