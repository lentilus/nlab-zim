Idea

A simplicial weak equivalence is a weak equivalence in the standard homotopy theory of simplicial sets, hence with respect to the classical model structure on simplicial sets.

Definition

A morphism ff between simplicial sets is a simplicial weak equivalence if any of the following equivalent conditions is satisfied (where Ex ∞Ex^\infty denotes Kan fibrant replacement):

  • Ex ∞(f)Ex^\infty(f) is a simplicial homotopy equivalence.

  • Ex ∞(f)Ex^\infty(f) has the right homotopy lifting property with respect to ∂Δ n→Δ n\partial\Delta^n\to\Delta^n.

  • Ex ∞(f)Ex^\infty(f) induces isomorphisms on simplicial homotopy groups, i.e., Ex ∞(f)Ex^\infty(f) induces an isomorphism on π 0\pi_0 and all homotopy groups for any choice of basepoints.

  • Hom(f,A)Hom(f, A) is a simplicial homotopy equivalence for every Kan complex AA (where HomHom denotes the hom-functor).

  • ff has the right homotopy lifting property with respect to Sd i∂Δ n→Sd iΔ nSd^i \partial\Delta^n \to Sd^i \Delta^n (allowing subdivisions for homotopies also).

  • ff belongs to the class of weak equivalences in the classical model structure on simplicial sets, whose cofibrations are monomorphisms and fibrant objects are Kan complexes.

  • The morphism ff is a composition of a trivial cofibration and a trivial fibration on the classical model structure on simplicial sets, both of which are defined using lifting properties.

  • Applying the category of elements functor produces a Thomason weak equivalence of categories. The class of Thomason weak equivalences forms the smallest basic localizer, i.e., the smallest class of functors between small categories that contains identities, is closed under retracts and the 2-out-of-3 property, contains all functors A→1A \to 1 for which the category A has a terminal object, and is locally determined: if u:A→Bu\colon A\to B and w:B→Cw\colon B\to C are functors, with v=w∘u:A→Cv=w\circ u\colon A\to C, and for any c∈Cc\in C the induced functor of comma categories v/c→w/cv/c\to w/c is a Thomason weak equivalence, then so is uu.
