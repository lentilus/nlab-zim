Ingredients

Definition

A smooth map f:X→Yf \,\colon\, X \to Y between smooth manifolds is called stable if every nearby smooth function, hence every function in some open neighbourhood of ff inside the mapping space C ∞(X,Y)⊂C 0(X,Y)C^\infty(X,Y) \subset C^0(X,Y), is equal to ff up to conjugation with a pair of diffeomorphisms.

Similarly, ff is infinitesimally stable if this statement holds to first order in derivatives, in a suitable sense.

(due to Mather 68, see Ruas 22, Def. 2.2, Def. 3.3).

Statement

Proposition

A proper smooth map between smooth manifolds is “stable” (Def. ) if and only if it is infinitesimally stable.

(Mather 70, Thm. 4.1, Ruas 22, Thm. 3.11)
