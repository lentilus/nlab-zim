Idea

An ordinary locally small category 𝒞\mathcal{C} has for any ordered pair of objects x,yx,y a hom-set 𝒞(x,y)\mathcal{C}(x,y)—an object in the category Set.

For 𝒞\mathcal{C} more generally an enriched category over a closed monoidal category 𝒱\mathcal{V}, there is – by definition – for all x,yx,y an object 𝒞(x,y)∈objV\mathcal{C}(x,y) \in obj V that plays the role of the “collection of morphisms” from xx to yy.

Accordingly, if here 𝒱\mathcal{V} is a category of “spaces” of sorts, then one also speaks of a hom space. For instance if 𝒱\mathcal{V} =vector spaces such that 𝒞\mathcal{C} is a linear category, then hom-spaces are vector spaces.

Or if 𝒱\mathcal{V}=topological spaces such that 𝒞\mathcal{C} is topologically enriched category, then hom-spaces are topological spaces. If this last example is regarded in the context of homotopy theory, then one may consider just the homotopy type of these topological spaces, which is equivalently modeled as a simplicial set (Kan complex) and thought of as an infinity-groupoid. In all these cases people still often speak of “hom spaces”, but see at derived hom space.

Examples

  • The category Prop of propositions is enriched over itself. Hence for any two proposition a,ba,b, there is a hom-proposition Prop(A,B)Prop(A,B). This is the implication proposition a⇒ba \implies b.

  • The category Set of sets is enriched over itself. Hence for any two sets A,BA,B, there is a hom-set Set(A,B)Set(A,B). This is the function set A→BA \to B.

  • The category Grpd of groupoids is enriched over itself. Hence for any two groupoids A,BA,B, there is a hom-groupoid Grpd(A,B)Grpd(A,B). This is the functor category Func(A,B)Func(A,B).

  • The category Pos of posets is enriched over itself. Hence for any two posets A,BA,B, there is a hom-poset Pos(A,B)Pos(A,B), the poset of monotones.
