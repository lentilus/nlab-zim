Definition

A σ\sigma-complete lattice is a lattice (L,≤,⊥,∨,⊤,∧)(L, \leq, \bot, \vee, \top, \wedge) with a function

⋁ i:ℕ(−)(i):(ℕ→L)→L\Vee_{i:\mathbb{N}} (-)(i): (\mathbb{N} \to L) \to L

such that

  • for all natural numbers n∈ℕn \in \mathbb{N} and sequences s:ℕ→Ls: \mathbb{N} \to L

    s(n)≤⋁ i∈ℕs(i) s(n) \leq \Vee_{i \in \mathbb{N}} s(i)

  • for all elements x∈Lx \in L and sequences s:ℕ→Ls:\mathbb{N} \to L, if s(n)≤xs(n) \leq x for all natural numbers n∈ℕn \in \mathbb{N}, then

    ⋁ i∈ℕs(i)≤x\Vee_{i \in \mathbb{N}} s(i) \leq x

Properties

Given an element a∈La \in L, let t↦at \mapsto a denote the constant sequence to aa, and given an element a∈La \in L and a sequence s:ℕ→Ls:\mathbb{N} \to L, let T(a,s):ℕ→LT(a, s):\mathbb{N} \to L denote the sequence inductively defined by T(a,s,0)=aT(a, s, 0) = a and T(a,s,n+1)=s(n)T(a, s, n + 1) = s(n). For simplicity, we denote the infinitary operation as

V(s)≔⋁ i∈ℕs(i):(ℕ→L)→LV(s) \coloneqq \Vee_{i \in \mathbb{N}} s(i):(\mathbb{N} \to L) \to L

The infinitary operation on a σ\sigma-complete lattice LL is

  • commutative in that given a sequence s:ℕ→Ls:\mathbb{N} \to L and a bijection b:ℕ≅ℕb:\mathbb{N} \cong \mathbb{N},
V(s)=V(s∘b)V(s) = V(s \circ b)
  • idempotent in that given an element a∈La \in L,
V(t↦a)=aV(t \mapsto a) = a
  • associative in that given an element a∈La \in L and sequences r:ℕ→Lr:\mathbb{N} \to L and s:ℕ→Ls:\mathbb{N} \to L,
V(T(V(T(a,r)),s))=V(T(V(T(a,s)),r))V(T(V(T(a, r)), s)) = V(T(V(T(a, s)), r))

i.e. using concatenation to denote the infinitary operation

(…r 3r 2r 1r 0a)s 0s 1s 2s 3…=…r 3r 2r 1r 0(as 0s 1s 2s 3…)(\ldots r_3 r_2 r_1 r_0 a) s_0 s_1 s_2 s_3 \ldots = \ldots r_3 r_2 r_1 r_0 (a s_0 s_1 s_2 s_3 \ldots)

The commutative property being satisfied ensures that all other possible associativity equations are satisfied as well.

  • The bottom element ⊥∈L\bot \in L is a neutral element of the infinitary operation in the sense that for all elements a∈La \in L
V(T(a,t→⊥))=aV(T(a, t \to \bot)) = a

The commutative property being satisfied ensures that all other possible neutral element equations are satisfied as well.
