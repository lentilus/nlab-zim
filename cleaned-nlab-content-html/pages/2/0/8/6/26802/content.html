Definition

If we view a matrix with entries in some set XX with rows labelled by elements in the index set II and rows labelled by elements in JJ as a function A:I×J→XA \colon I\times J\to X then a partitioned matrix (also called a block matrix) is a matrix together with partitions of the sets of row labels and column labels.

For partitions I=I 1∐I 2∐…∐I kI = I_1\coprod I_2\coprod\ldots\coprod I_k, J=J 1∐J 2∐…∐J lJ = J_1\coprod J_2\coprod\ldots\coprod J_l, there are corresponding submatrices, cells or blocks A L s J r:J r×L s→XA^{J_r}_{L_s}:J_r\times L_s\to X which are matrices defined by A L s J r(i,j)=A(i,j)A^{J_r}_{L_s}(i,j) = A(i,j) as long as (i,j)⊂J r×L s(i,j)\subset J_r\times L_s. Conversely, AA is determined by A L s J rA^{J_r}_{L_s} for all 1≤r≤k1\leq r\leq k and 1≤s≤l1\leq s\leq l. Thus, one views a partitioned matrix as such a labelled collections of blocks.

One often uses some ordering on II and JJ and partitions which respect the ordering.

Properties

Gauss elimination procedure, row operations, Gauss decomposition, quasideterminants, computation of inverse matrix, make sense and are performed alike the classical case, but with the order of multiplicating blocks essential. However, the determinant does not make sense or does not behave well even when it is still accidentaly defined.

Heredetary property of quasideterminants: quasideterminant at (i,j)(i,j) of block quasideterminant at (I r,J s)(I_r,J_s) where i∈I ri\in I_r, j∈J sj\in J_s equals the quasideterminant of the original matrix at (i,j)(i,j). In particular, inverse of a block matrix has entries of entries which are entries of inverse of the original matrix. Consequently, linear equations may be solved by block version of Gaussian elimination and the result reinterpreted in terms of original matrix labels.
