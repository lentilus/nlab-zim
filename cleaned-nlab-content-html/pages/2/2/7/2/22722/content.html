Axiom of stack completion

Definition

An internal category 𝔸\mathbb{A} in an elementary topos ℰ\mathcal{E} is called an (intrinsic) stack if the indexed category that it represents, (X∈ℰ)↦ℰ(X,𝔸)∈Cat(X\in \mathcal{E}) \mapsto \mathcal{E}(X,\mathbb{A}) \in Cat, is a stack for the regular topology of ℰ\mathcal{E}. An internal functor is called a weak equivalence if it is internally essentially surjective and fully faithful; this is strictly weaker than being an internal equivalence if the axiom of choice does not hold in ℰ\mathcal{E}. However, if f:𝔸→𝔹f:\mathbb{A} \to \mathbb{B} is a weak equivalence and ℂ\mathbb{C} is a stack, then the induced functor Cat(ℰ)(𝔹,ℂ)→Cat(ℰ)(𝔸,ℂ)\mathrm{Cat}(\mathcal{E})(\mathbb{B},\mathbb {C})\to \mathrm{Cat}(\mathcal{E})(\mathbb{A},\mathbb{C}) is an equivalence.

We say that ℰ\mathcal{E} satisfies the axiom of stack completions (ASC) if every internal category admits a weak equivalence to an internal category that is a stack (see Bunge-Hermida).

Examples

  • If ℰ\mathcal{E} satisfies the axiom of choice, then every internal category is a stack, so ASC holds trivially.

  • If ℰ\mathcal{E} is a Grothendieck topos, then internal stack completions can be constructed using the small object argument, as fibrant replacements in the model structure on Cat(ℰ)\mathrm{Cat}(\mathcal{E}) constructed by Joyal and Tierney, so it satisfies ASC.
